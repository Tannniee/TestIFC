# Complete package integration

The Info catalogue contains all 62 workspace packages (57 published), with their
actual imported versions and 210 workspace dependency edges. Source, tests and
matching documentation accompany the manifests. Info is a workspace catalogue;
it does not claim all headless and provider packages are bundled in the desktop EXE.

New package sources include ai, ids-agent, ids-authoring, report-contract, semantic
and source-autodesk. The customized viewer interface remains in place.

Windows BCF storage retains write-capable directory flushes and identity/claim
checks; successful immutable self-process identity may be reused, foreign identities
are queried afresh. A storage volume must support the required flush operations.

See [the publication and audit summary](../PUBLICATION-v2.0.1.md).
