## Implementation

- Project Browser and Properties stay mounted and slide over a stable canvas.
  This avoids reallocating the WebGL framebuffer and changing camera aspect
  each time a panel opens. Closed panels are inert and hidden from accessibility.
  Content and filter state survive toggles; reduced motion disables animation.
- Settings has General, Navigation, BIM–GIS and Storage tabs, saved VI/EN and
  appearance controls, keyboard tab navigation and localized status messages.
  It appears above the workspace panels and scrolls on short windows.
- BIM filters compose 1–8 scalar Pset/Qto conditions with AND/OR. Text contains
  treats SQL wildcard characters literally; ordered comparisons require finite
  numbers. Qto comparisons use the existing SI-normalized semantic index.
- Authored field suggestions come from the active IFC index. The suggestion
  catalog is bounded to 2,000 fields; free-text entry remains available.
- Server results use deterministic keyset pages of 500. The frontend retrieves
  every page, checks model ownership, totals and advancing cursors, and enables
  bulk actions only after completion. Records without geometry are counted but
  excluded from selection. Tree name/type/scope filters also narrow the group.
- Visibility is read by occurrence ID, including repeated/shared geometry.
  Isolation explicitly hides the geometry occurrences before showing the group.

## Research choices

The [Svelte transition documentation](https://svelte.dev/docs/svelte/transition)
describes reversible transitions. Persistent panels with CSS transform/opacity
also retain their DOM and state, while avoiding layout changes to the canvas.

[IfcOpenShell selector syntax](https://docs.ifcopenshell.org/ifcopenshell-python/selector_syntax.html)
supports richer IFC queries. For this release, parameterized queries over our
existing scalar index give predictable paging and reuse normalized quantities.
This feature does not evaluate arbitrary selector expressions or extract geometry
to answer a semantic query.
